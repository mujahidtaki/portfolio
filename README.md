# Personal Portfolio Website

A responsive personal portfolio built with HTML, CSS, and JavaScript.

## How to run
1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Files
- `index.html` — page content and sections
- `style.css` — responsive styling
- `script.js` — mobile navigation and current year

## Before submitting
- Check your name and education details.
- Replace the general GitHub and LinkedIn links with your own profile links.
- Add actual links to your projects if available.
- Never publish passwords, API keys, or private information.
